# Back Cover Copy

Literature carries invisible gender assumptions that shape how we read, and what we see. Experiencing the same story through different perspectives reveals the narrative patterns and power structures woven into the story.

This volume was produced using regender.xyz, free and open source software that systematically transforms gendered language in books.

The software processed Jane Austen's Pride & Prejudice (1813) to generate four complete versions of the novel: genders swapped, all male, all female, and gender neutral.
